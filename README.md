# Machine Learning Projects

A collection of machine learning projects I built while learning and practicing classical machine learning.

## Projects

### 1. Breast Cancer Prediction

A binary classification project using the Breast Cancer Wisconsin dataset to predict whether a tumor is benign or malignant.

**Algorithm:** Logistic Regression

**Concepts:** Data preprocessing, feature scaling, train-test split, classification evaluation

### 2. House Price Prediction

A regression project that predicts house prices based on different features of residential properties.

**Algorithm:** Linear Regression

**Concepts:** Data exploration, feature selection, regression, model evaluation

### 3. Iris Classifier

A classification project using the Iris dataset to predict the species of a flower based on its measurements.

**Algorithm:** K-Nearest Neighbors (KNN)

**Concepts:** Feature scaling, train-test split, classification evaluation, model experimentation

### 4. Titanic Survival Prediction

A classification project that predicts whether a passenger survived the Titanic disaster using passenger and travel information.

**Algorithm:** Random Forest Classifier

**Concepts:** Data preprocessing, feature engineering, categorical encoding, pipelines, cross-validation, hyperparameter tuning, model evaluation
